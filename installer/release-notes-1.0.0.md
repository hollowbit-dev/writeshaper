The first release of Writeshaper: fix and polish your writing in any app, privately.

- Select text anywhere, press ⌥ Space (Mac) or Alt + Shift + Space (Windows): fix mistakes, or make it clearer, shorter, friendlier or more professional, or translate it.
- The Write tab checks as you type and explains every fix.
- Runs on your own computer. The writing model (Standard 1.9 GB, or Best 2.7 GB) downloads once inside the app; after that it works offline.

Mac: right-click Writeshaper → Open the first time. Windows: if SmartScreen appears, click More info → Run anyway.
