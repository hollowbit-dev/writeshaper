Confidentialité

En bref : vos textes ne quittent jamais votre ordinateur.

Ce que Writeshaper fait de votre texte

Il lit le texte que vous sélectionnez ou tapez, l’envoie au modèle d’écriture qui tourne sur votre propre ordinateur (un programme appelé llama.cpp qui n’écoute que sur votre machine) et vous montre le résultat. Le texte n’est ni enregistré sur le disque, ni journalisé, ni envoyé nulle part.

Quand Writeshaper utilise internet

Une fois, pour télécharger le modèle d’écriture depuis Hugging Face quand vous le demandez. Une fois par jour, pour vérifier sur GitHub s’il existe un nouveau numéro de version, sauf si vous le désactivez dans les réglages. Aucune de ces requêtes ne contient ce que vous avez écrit ni quoi que ce soit sur vous.

Votre presse-papiers

Pour récupérer votre sélection et coller le résultat, Writeshaper utilise le presse-papiers un instant, puis y remet ce qui s’y trouvait avant.

Ce site

Pas de cookies, pas d’analyses, pas de traceurs. La démo de la page d’accueil rejoue des réponses enregistrées dans la page ; rien de ce que vous y faites n’est envoyé nulle part.
