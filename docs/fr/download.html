Télécharger Writeshaper

Version 1.0.0. Gratuit, sans compte. Environ 111 Mo, puis le modèle d’écriture se télécharge une fois dans l’appli.

Mac

macOS 12 ou plus récent.

Apple Silicon (M1 ou plus récent) Mac Intel
Première ouverture ?

Writeshaper ne vient pas de l’App Store : la première fois, faites un clic droit sur Writeshaper dans Applications et choisissez Ouvrir, puis à nouveau Ouvrir. Ensuite, il s’ouvre normalement. À la première utilisation du raccourci, autorisez Writeshaper dans Réglages Système → Confidentialité et sécurité → Accessibilité, pour qu’il puisse copier et coller à votre place.

Windows

Windows 10 ou 11, 64 bits.

Télécharger pour Windows
Windows dit avoir protégé votre PC ?

Les nouvelles applis de petits studios affichent ce message tant que peu de gens les ont installées. Cliquez sur Informations complémentaires, puis sur Exécuter quand même. L’installateur ajoute aussi le runtime Visual C++ de Microsoft si votre PC ne l’a pas encore.
