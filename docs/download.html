Download Writeshaper

Version 1.0.0. Free, no account. About 111 MB, then a one-time writing model download inside the app.

Mac

macOS 12 or later.

Apple Silicon (M1 or newer) Intel Mac
First time opening it?

Writeshaper isn’t from the App Store, so the first time, right-click Writeshaper in Applications and choose Open, then Open again. After that it opens normally. When you first use the shortcut, allow Writeshaper under System Settings → Privacy & Security → Accessibility, so it can copy and paste for you.

Windows

Windows 10 or 11, 64-bit.

Download for Windows
Windows says it protected your PC?

New apps from small studios show this until enough people have installed them. Click More info, then Run anyway. The installer also adds Microsoft’s Visual C++ runtime if your PC doesn’t have it yet.
