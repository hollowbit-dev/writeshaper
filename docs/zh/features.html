它能做的一切

一个私密的写作助手，待在菜单栏或系统托盘里，任何应用都能用，从不上传一个字。

任何应用都能用

一个快捷键，在邮件、Word、Slack 或浏览器上都能用。选中、按键，Replace 会把结果粘贴回去。

边写边纠错

Write 标签页实时标出错误，并解释每处修改。可以逐条接受，也可以一次全部改好。

调整语气

更清楚、更简短、更友好或更专业，一键完成。也可以直接告诉它，比如“改成列表”。

翻译

把消息翻译成 20 种语言之一，读起来像母语者写的。

从设计上保护隐私

模型在你的电脑上运行。你写的内容不会被上传、保存，也不会被用来训练任何东西。

离线可用

在飞机上、火车上，关掉 Wi-Fi 也能用。第一次下载之后，再也不需要联网。

在你写字的每个地方，都写得更好。

Mac 和 Windows 免费使用。安装包约 111 MB，之后一次性下载 1.9 GB 的写作模型。
