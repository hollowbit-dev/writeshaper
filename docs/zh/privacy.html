隐私

一句话：你写的内容永远不会离开你的电脑。

Writeshaper 如何处理你的文字

它读取你选中或输入的文字，交给在你电脑上运行的写作模型（一个叫 llama.cpp 的程序，只在你的设备内部监听），然后把结果显示给你。文字不会保存到磁盘，不会被记录，也不会发送到任何地方。

Writeshaper 什么时候联网

一次：在你要求时，从 Hugging Face 下载写作模型。每天一次：在 GitHub 上检查有没有新的版本号，除非你在设置里关掉。这两个请求都不包含你写的任何内容，也不包含任何关于你的信息。

你的剪贴板

为了拿到你选中的文字并粘贴结果，Writeshaper 会短暂使用剪贴板，之后再把原来的内容放回去。

本网站

没有 Cookie，没有统计分析，没有追踪器。首页的演示播放的是保存在页面里的结果；你在上面做的任何操作都不会被发送出去。
