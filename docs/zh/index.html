常见问题

Writeshaper 真的免费吗？

是的。没有试用期，没有高级版，不用注册，也没有广告。它以 MIT 许可证开源。如果它帮到了你，可以在 Ko-fi 上支持工作室，但这从来不是必须的。

我写的内容会被上传吗？

不会。Writeshaper 在你自己的电脑上运行写作模型。你的文字从不离开电脑，连 Hollowbit 也收不到。应用只在两种情况下联网：下载一次模型；以及（除非你关掉）每天在 GitHub 上检查一次有没有新版本。

它有多大？

安装包约 111 MB。第一次打开时，Writeshaper 会下载一次写作模型：Standard 为 1.9 GB；如果想让它多发现一些问题，可以选 2.7 GB 的 Best。你随时可以在设置里删除或切换模型。

它能在哪些应用里用？

几乎所有能选中文字的应用：浏览器里的邮件、Gmail 和 Outlook，Word、Google 文档、Slack、Discord、WhatsApp、备忘录等。选中文字，按下快捷键，Replace 会把新版本粘贴回去。
