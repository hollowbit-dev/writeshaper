Mac

macOS 12 或更新版本。

Apple 芯片（M1 或更新） Intel Mac
第一次打开？

Writeshaper 不是从 App Store 下载的，所以第一次请在“应用程序”里右键点按 Writeshaper，选择打开，然后再点一次打开。之后就能正常打开了。第一次使用快捷键时，请在“系统设置 → 隐私与安全性 → 辅助功能”里允许 Writeshaper，这样它才能替你复制和粘贴。

Windows 提示“已保护你的电脑”？

小工作室的新应用在安装的人足够多之前都会出现这个提示。点更多信息，再点仍要运行。如果你的电脑还没有微软的 Visual C++ 运行库，安装程序也会一并装上。
