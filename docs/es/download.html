Descargar Writeshaper

Versión 1.0.0. Gratis, sin cuenta. Unos 111 MB y luego el modelo de escritura se descarga una vez dentro de la app.

Mac

macOS 12 o posterior.

Apple Silicon (M1 o posterior) Mac Intel
¿Es la primera vez que lo abres?

Writeshaper no viene de la App Store, así que la primera vez haz clic derecho en Writeshaper en Aplicaciones y elige Abrir, y después Abrir otra vez. A partir de ahí se abre con normalidad. Cuando uses el atajo por primera vez, permite Writeshaper en Ajustes del Sistema → Privacidad y seguridad → Accesibilidad, para que pueda copiar y pegar por ti.

Windows

Windows 10 u 11, 64 bits.

Descargar para Windows
¿Windows dice que protegió tu PC?

Las apps nuevas de estudios pequeños muestran este aviso hasta que suficiente gente las instala. Haz clic en Más información y luego en Ejecutar de todas formas. El instalador también añade el runtime de Visual C++ de Microsoft si tu PC aún no lo tiene.

Qué se descarga

La appunos 111 MB
Modelo de escritura Standard (recomendado)1,9 GB, una vez
Modelo de escritura Best (opcional)2,7 GB, una vez

El modelo se descarga dentro de la app la primera vez que la abres, y puedes pausar y reanudar la descarga. Viene de Hugging Face, fijado a una versión exacta y comprobado con SHA-256.
