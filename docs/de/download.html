Writeshaper herunterladen

Version 1.0.0. Kostenlos, ohne Konto. Etwa 111 MB, danach lädt die App das Schreibmodell einmal herunter.

Mac

macOS 12 oder neuer.

Apple Silicon (M1 oder neuer) Intel-Mac
Zum ersten Mal öffnen?

Writeshaper kommt nicht aus dem App Store. Klicke beim ersten Mal mit der rechten Maustaste in Programme auf Writeshaper und wähle Öffnen, dann noch einmal Öffnen. Danach startet es normal. Wenn du den Kurzbefehl zum ersten Mal nutzt, erlaube Writeshaper unter Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen, damit es für dich kopieren und einfügen kann.

Windows

Windows 10 oder 11, 64 Bit.

Für Windows laden
Windows sagt, es habe deinen PC geschützt?

Neue Apps kleiner Studios zeigen diese Meldung, bis genug Leute sie installiert haben. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Das Installationsprogramm installiert auch die Visual-C++-Laufzeit von Microsoft, falls dein PC sie noch nicht hat.

Was heruntergeladen wird

Die Appetwa 111 MB
Schreibmodell Standard (empfohlen)1,9 GB, einmalig
Schreibmodell Best (optional)2,7 GB, einmalig

Das Modell wird beim ersten Öffnen in der App heruntergeladen und kann pausiert und fortgesetzt werden. Es kommt von Hugging Face, auf eine genaue Version festgelegt und per SHA-256 geprüft.
